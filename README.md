# Educaro Applicant Journey

Working frontend prototype for applicants in India exploring study, vocational training, or employment routes in Germany.

## Run locally

```bash
npm install
npm run dev
```

## Included

- Applicant intake profile
- Supporting-document selection
- Progressive completeness indicator
- Clear missing-information request
- Qualification-review readiness and next-step recommendation

The interface deliberately does not invent applicant information or produce an automatic eligibility decision.
